# 植牙這件事，醫師陪你聊

14 頁繁體中文有聲漫畫衛教。角色為虛構人物，醫療內容沿用原版查核資料。

- 開啟 index.html，可離線使用圖片、動畫、旁白。
- 上下頁按鈕或左右方向鍵換頁，點「播放本頁旁白」聆聽。
- 支援連續播放、速度調整、旁白文字與手機直式閱讀。
- 完整資料來源見「旁白稿與來源.md」與簡報內資料來源。
- 透過本機伺服器開啟 hyperframes.html 可使用 HyperFrames 內建講者模式。

原版永久保留：https://maskywg.github.io/dental-implant-patient-education/

插圖由 ImageGen 製作，僅為概念示意，非患者真實影像。旁白使用 zh-TW-HsiaoChenNeural 合成語音，對話角色由單一旁白朗讀。個別診斷、手術風險、清潔與用藥仍依醫療團隊說明。

修改來源：content.json、slides.json。更新對應 MP3 後，執行 python3 scripts/build.py 重建。
